# Student Management System

## About
A simple student management application built using Python and SQLite.

## Features
- Add student records
- View all students
- Search students by ID
- Delete student records

## Technologies Used
- Python
- SQLite
- VS Code

## How to Run
1. Install Python.
2. Download the project.
3. Open the project folder in VS Code.
4. Run `py main.py` in the terminal.
